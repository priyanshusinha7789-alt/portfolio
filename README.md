# PRIME FOCUS — Digital Studio Portfolio Website

> **"Websites That Make Local Businesses Stand Out."**  
> Modern websites for cafés, restaurants, shops, coaching centres, and growing local businesses.

---

## 🌟 Overview

PRIME FOCUS is a creative web-development studio portfolio built with:
- **React 19 & Vite**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Smooth Scroll & Micro-Animations**
- **Embedded Interactive Live Preview Modal**
- **Netlify-Ready Deployment Configuration**

---

## 🎨 Design System

- **Palette**: Warm Espresso Brown (`#2B1B14`), Dark Roast (`#3A241B`), Warm Brown (`#6F4E37`), Cream (`#F5EFE6`), Warm White (`#FCFAF7`), and Light Beige (`#EDE2D4`).
- **Aesthetic**: Minimal luxury, premium paper texture, elegant typography, warm coffee-inspired branding.
- **Tone**: Authentic, honest, and direct communication (Phone calls and WhatsApp).

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

---

## 🌐 Deploy to Netlify

This repository includes `netlify.toml` and `public/_redirects` preconfigured:

1. Connect this GitHub repository in your [Netlify Dashboard](https://app.netlify.com/).
2. Netlify will automatically detect:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
3. Click **Deploy Site** — your site will be live instantly!
